==================================================
MOBILE RESPONSIVE RULES
==================================================

On mobile:

All complex layouts must become single-column.

Important:
- no horizontal scrolling
- no fixed large widths
- no content clipping
- no overlapping text
- no oversized illustrations
- no tiny body text

Use approximately:
16px horizontal page padding minimum.

Headings must scale using clamp().

Suggested approach:

font-size: clamp(...)

Avoid hardcoded heading sizes that break mobile screens.

Buttons:
- full width where appropriate
- minimum 44px touch height

Cards / panels:
width: 100%

Images:
max-width: 100%;
height: auto;

Use object-fit carefully.

==================================================

==================================================

Only use absolute positioning for decorative visuals.
